# 🗳️ Algorand Voting System

## 📌 Project Description

This project is a secure and transparent voting system built using the Algorand blockchain. It ensures that each vote is recorded immutably and prevents fraud or duplication.

## 🎯 Objective

To create a decentralized voting platform where users can cast votes securely and results are tamper-proof.

## ⚙️ Technologies Used

* Algorand Blockchain
* Python
* Smart Contracts (Algorand SDK)

## 🚀 Features

* One person, one vote
* Transparent voting process
* Secure data storage
* Fast transactions using Algorand

## 📂 Project Structure

* `main.py` → Voting logic
* `README.md` → Project documentation

## 🔗 Future Scope

* Web interface for users
* Authentication system
* Real-time results dashboard
